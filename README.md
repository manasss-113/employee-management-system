# Employee Management System

A full-stack Employee Management System built using Spring Boot, Spring Security, JWT Authentication, MySQL, and Swagger.

## Live Demo

Deployed URL:
https://employee-management-system-production-a911.up.railway.app

Swagger API Documentation:
https://employee-management-system-production-a911.up.railway.app/swagger-ui/index.html


## Features

- User Registration
- User Login with JWT Authentication
- Secure API access using Spring Security
- Employee CRUD Operations
- Add Employee
- View All Employees
- Update Employee Details
- Delete Employee
- MySQL Database Integration
- API Documentation using Swagger OpenAPI


## Technology Stack

### Backend
- Java 21
- Spring Boot 3
- Spring MVC
- Spring Data JPA
- Spring Security
- JWT Authentication

### Database
- MySQL
